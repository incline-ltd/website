# Security

Report a security concern through a [private vulnerability report](https://github.com/incline-ltd/website/security/advisories/new). Include the affected file, a small reproduction, and the expected impact. Do not put credentials, personal information, or an exploitable issue in a public issue or pull request.

The maintained version is the current default branch.

This repository is a static architecture example. The contact form validates sample input locally and does not send or store it. Product screens and chat interactions are demonstrations. There are no production credentials or deployment services in this repository.

If a private report cannot be submitted, do not publish sensitive details in a public issue. You can use the [Incline contact page](https://inclineltd.com/contact/) to request a private reporting channel without including the vulnerability itself.
