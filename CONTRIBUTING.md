# Contributing

Keep changes focused and explain what improves for someone reading or using the example.

Use the existing HTML, CSS, and classic JavaScript structure. Extend the shared shell, design tokens, or preview registry when they already own the behavior. A framework or build pipeline should solve a demonstrated need before it is added.

Keep the contact form local. Do not add a real endpoint, telemetry, stored submissions, credentials, or production deployment configuration. Use invented sample content for previews.

## Before opening a pull request

Run the commands in the [README](README.md#check-changes). Check affected pages at desktop and phone widths, with a keyboard, and in both device themes. For form changes, confirm that submitting stays on the page and sends no request.

Describe the change and the checks you ran. Include a screenshot when the appearance changes, after checking that it contains no personal information.

Source code contributions use the [MIT license](LICENSE). Branding and marketing content remain subject to [BRANDING.md](BRANDING.md). Do not add third party assets without permission and the required attribution.

Report security concerns privately using [SECURITY.md](SECURITY.md).
